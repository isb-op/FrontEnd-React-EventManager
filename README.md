# Event Manager - Frontend

Um projeto em React para o gerenciamento de eventos voltado para administradores, com conexão a uma [API RESTful](https://github.com/isb-op/eventmanager-backend)

### Funcionalidades
O sistema oferece três telas principais:

🔒 Tela de Login

Acesso ao sistema com autenticação segura.

📝 Tela de Cadastro

Registro de novos administradores no sistema.

📅 Tela de Eventos

Gerenciamento completo de eventos, incluindo:

Cadastro de novos eventos.
Edição de eventos existentes.
Exclusão de eventos obsoletos.
Listagem de eventos para visualização geral.
